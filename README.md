# NailStudio
Sistema web desenvolvido para facilitar o gerenciamento de clientes, serviços e agendamentos de um pequeno estabelecimento comercial.


# Sobre o projeto

Este projeto foi desenvolvido com o objetivo de modernizar e simplificar o processo de gerenciamento de agendamentos, substituindo controles manuais por uma solução digital centralizada.

A aplicação permite organizar informações de clientes, serviços oferecidos e horários agendados, proporcionando maior praticidade, organização e eficiência na rotina administrativa do estabelecimento.

O desenvolvimento foi realizado de forma incremental, utilizando uma abordagem ágil e priorizando as necessidades identificadas durante o levantamento inicial.

# Objetivos

Facilitar o gerenciamento de agendamentos.

Centralizar as informações dos clientes.

Organizar os serviços oferecidos pelo estabelecimento.

Reduzir a dependência de controles manuais.

Proporcionar uma interface simples e intuitiva.

Melhorar a organização e a eficiência dos processos administrativos.

# Funcionalidades

Cadastro e gerenciamento de clientes.

Cadastro e gerenciamento de serviços.

Criação e consulta de agendamentos.

Armazenamento persistente das informações.

Integração com banco de dados na nuvem.

# Banco de dados 

O projeto utiliza o Supabase como infraestrutura de banco de dados, permitindo armazenar e gerenciar as informações relacionadas aos clientes, serviços e agendamentos.

A integração possibilita a persistência dos dados e a comunicação entre a aplicação e a base de informações.


# Metodologia

O desenvolvimento foi conduzido utilizando uma abordagem ágil, com implementação incremental e priorização das funcionalidades essenciais.

A primeira versão funcional foi disponibilizada em 10 de novembro de 2026, para utilização inicial e avaliação pela responsável pelo estabelecimento.

# Resultados esperados

A solução busca proporcionar maior agilidade na realização dos agendamentos, melhorar a organização das informações e reduzir problemas associados ao controle manual de horários.

Na avaliação inicial, foi estimada uma melhoria de aproximadamente 20% no tempo necessário para realizar os agendamentos. Esse indicador é preliminar e baseado na percepção inicial de utilização, não em uma medição controlada.
